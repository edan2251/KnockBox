Knockbox 온라인 시험 (친구용)

현재 소스 안내 (2026-11-06 맵 순환)
  일반 Main 경기는 GameMaps 등록 목록을 순환한다. 1개면 같은 맵, 2~8개면 직전 라운드와 다른 맵을 사용한다.
  온라인 프로토콜은 9이며 양쪽의 맵 목록 순서/이름/전체 지형을 확인한 뒤 시작한다.
  프로토콜 8 이하의 구 빌드와는 접속하지 않는다. 입력 기록 형식은 v8이고 과거 기록은 보존한다.
  이 변경의 새 배포 빌드나 친구와의 2PC 시험은 아직 수행하지 않았다.
  아래 프로토콜 6/4 등은 당시 빌드의 과거 안내이며 현재 소스 규격으로 해석하지 않는다.

과거 소스 안내 (2026-11-04 CR-005)
  새 UI는 방 만들기 / 코드로 참가 / 연습으로 연결된다. 2라운드 선승으로 세트 종료,
  세트 패자는 카드 한 장을 획득하고 다음 라운드로 간다. 5세트 선승이면 경기 종료.
  이번 카드는 효과 없이 보유만 하며, 15초 내 미선택 시 자동 선택한다.
  VS는 경기 시작 때 한 번만 표시한다. 라운드 점 두 개가 세트 점 하나로 합쳐지고 경기장이 재구성된다.
  결과 화면에서 3.5초 뒤 O를 한 번 클릭해 준비한다. 준비한 쪽만 밝아지고 양쪽 준비 후 재대결한다.
  X는 메인으로 돌아간다. 아래의 왼쪽 클릭 홀드 재대결은 과거 빌드 안내다.
  온라인 프로토콜은 6이다. 구 프로토콜 1~5 실행 파일과 접속하지 않는다.
  아래 영문 버튼 이름·배포 절차는 기존 시험 빌드 안내다. 이번에 기존 빌드/ZIP을 갱신하거나
  친구와의 2PC 시험을 진행하지 않았다. 새 UI 검수는 Main 씬 Play에서 한다.

필요한 것: Windows PC, 인터넷. 가입·설치·VPN·Steam 필요 없음.

1. 압축을 아무 폴더에나 푼다.
2. Knockbox.exe 실행.
   - "Windows의 PC 보호" 경고: "추가 정보" → "실행" (서명하지 않은 시험 빌드).
   - 방화벽에서 네트워크 허용을 물으면 "허용".
3. 한 사람: CREATE ROOM → 화면에 나온 6자리 코드를 상대에게 보낸다(COPY CODE로 복사).
   다른 사람: CODE 칸에 코드를 넣고 JOIN.
4. 연결되면 바로 경기 시작. 머리 위 YOU 가 내 캐릭터.

조작
  A / D 이동, SPACE 점프, 벽 쪽 + W 벽 오르기, 마우스 조준
  왼쪽 클릭을 8틱(약 0.13초) 전에 떼기 = 맨손 주먹 / 든 무기 사용. 누르는 순간에는 공격하지 않는다.
  왼쪽 클릭을 총 20틱(약 0.33초) 이상 누른 뒤 떼기 = 차징 박치기. 8~19틱에 떼면 공격 없이 취소.
  계속 유지하면 기본 설정에서 56틱(약 0.93초)에 자동 발사한다.
  주먹·무기 사용·박치기는 발동 순간의 커서 방향을 사용한다. Shift에는 기능이 없다.
  오른쪽 클릭 = 근처 무기 줍기 / 든 무기 커서 방향 투척 / 상대 잡기. 무기와 상대가 모두 범위 안이면 무기 우선.
  차징 중 오른쪽 클릭은 차징을 취소한 뒤 잡기 또는 든 무기 투척으로 전환한다.
  상대를 잡은 채 왼쪽 클릭을 새로 누르기 = 상대 던지기(탭 길이 판단 없이 기존 동작 유지).
  경기 끝: 두 사람이 함께 왼쪽 클릭을 누르고 있으면 재대결
  TAB 조작 안내, 연결이 끝나면 BACK TO MENU

무기 프로토타입
  매 라운드 전투 시작 5초 뒤 낙하지점을 표시하고 1초 예고 + 0.6초 낙하 후 바닥에 놓인다(낙하 피해 없음).
  프라이팬 / 권총 중 하나를 50:50으로 라운드당 한 번만 생성한다. 라운드 도중 추가 생성은 없다.
  프라이팬은 무제한 근접 타격. 권총은 6발, 짧은 클릭을 뗄 때 한 발, 최소 간격 0.4초, 피해 12.
  권총은 지형에 막히는 즉시 판정 사격이다. 길게 누르면 무기 대신 박치기를 충전한다.
  두 사람의 줍기가 같은 틱에 겹치면 가까운 사람이 줍고, 거리가 정확히 같으면 둘 다 줍지 않는다.
  무기는 부서지지 않는다. 벽꿍을 당하면 떨어뜨리며 바닥에 남아 다시 주울 수 있다.
  든 무기를 우클릭으로 던지면 피해 10·넉백 8을 준다. 벽에는 약하게 반사(0.3)하고 바닥에 멈춘 뒤 다시 주울 수 있다.
  투척 속도는 16에서 22로 늘렸다. 중력은 유지하므로 위쪽으로 겨누면 포물선으로 더 멀리 던질 수 있다.
  남은 탄약은 던지거나 떨어뜨리고 다시 주워도 유지한다. 0발이면 EMPTY로 계속 들고 있으며 자동 주먹 전환·재장전은 없다.
  맨손과 무기 보유 중 모두 같은 왼쪽 클릭 탭/홀드를 사용한다. 라운드 종료 때 무기 상태를 정리한다.

버전
  현재 탭/홀드·무기 투척 버전은 새 입력 기록 v8 / 온라인 프로토콜 4를 사용한다.
  이전 v7 / 프로토콜 3은 Shift 차징·우클릭 내려놓기 규칙이었다. 현재 안내는 새 피드백 규칙이다.
  두 사람은 같은 새 빌드를 사용해야 한다. 이전 프로토콜의 빌드와는 접속되지 않는다.
  이번 거리·최소 충전 조정은 v8/프로토콜 4를 유지하지만 설정 체크섬이 달라 조정 전 빌드와도 접속하지 않는다.

화면 맨 위: 내 자리(P1/P2), PING(왕복 지연 ms), DELAY(입력 지연 틱).
