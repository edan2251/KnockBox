# 게임 흐름 CP7 확인표

[게임 흐름 통합](../GAME_FLOW_PLAN.md)의 마지막 확인입니다. **이번에는 기능만 봅니다.** 화면이 마음에 들지 않는 부분은 고치지 않고 아래 "연출 메모"에 적어 두었다가 CP7 뒤에 한꺼번에 다듬습니다. 화면 때문에 확인 자체가 막히면(버튼이 가려 누를 수 없음, 준비했는지 알 수 없음 등) 그것만 바로 고칩니다.

결과는 칸에 `통과` / `문제: 무엇을 했더니 무엇이 됐다`로 적어 주세요. 조작은 [플레이 검수](../../team/PLAYTEST.md)를 따릅니다. 빠른 진행: 싸움 중 K(P1 승리)·L(P2 승리), O/P(즉사), 결과 공간 재시작 R.

## 1. 로컬 (Main Play 또는 빌드)

| # | 순서 | 볼 것 | 결과 |
|---|---|---|---|
| 1 | Play → 첫 메뉴 | 게임 시작·옵션·게임 종료만 보임 | |
| 2 | 옵션 | 값 버튼을 누르면 글자가 바뀜, 뒤로·Esc로 돌아감. 빌드에서는 화면 모드·해상도 적용과 재실행 뒤 유지 | |
| 3 | 게임 시작 → 뒤로 / Esc | 하위 메뉴 ↔ 첫 메뉴 | |
| 4 | 게임 시작 → 연습 | VS 없이 바로 경기 맵 재구성·3·2·1·GO | |
| 5 | 싸움 → O로 세트 패배 | 모놀리스 카드 선택 → 다음 라운드 | |
| 6 | K | 결과 공간: 승자 시상대 상승·점프, 패자 낙하, 그 뒤 자유 조작 | |
| 7 | 결과 공간에서 싸움·P로 KO | 점수 변화 없이 자리 위에서 재등장 | |
| 8 | R(또는 O) 두 번 빨리 | 준비 표시 뒤 취소, 경기 안 시작 | |
| 9 | R | 새 경기가 **등록 경기 맵**에서 VS 없이 시작 | |
| 10 | 다시 K → X | 메인으로 돌아감 | |
| 11 | 게임 종료 | 에디터면 Play 종료, 빌드면 꺼짐 | |

## 2. 온라인 (두 PC, 같은 새 빌드)

| # | 순서 | 볼 것 | 결과 |
|---|---|---|---|
| 1 | A: 게임 시작 → 방 만들기 | 큰 캐릭터가 튀어 올라 떨어진 뒤 로비에 혼자 떨어져 움직임, 방 코드·복사 | |
| 2 | A가 로비에서 움직이는 동안 B: 코드로 참가 | A 화면: 암전·맵 재구성 없이 A는 움직이던 그대로, B만 떨어짐. B 화면: A가 원래 자리에 보이고(낙하 자리에서 튀지 않음) B가 떨어짐 | |
| 3 | 로비에서 이동·싸움·KO | 재등장, 체력바 숨김, 점수 없음 | |
| 3a | B 화면에서 이동·싸움(입력 지연 0틱 빌드) | 끊김·뚝뚝 끊기는 이동 없음, 내 조작이 바로 반응, 상대가 크게 튀는지·타격 효과가 늦게 느껴지는지 적기. 역할을 바꿔(B가 방 만들기) 한 번 더 | |
| 4 | 한 명만 R/O | 머리 위 원이 채워지고 기다림, 상대 화면에도 보임. 다시 누르면 취소 | |
| 5 | 둘 다 준비 | 같은 순간 VS 없이 경기 시작 | |
| 6 | 경기 진행·카드 선택 | 기존과 같음(호버가 상대에게도 보임) | |
| 7 | 경기 끝 → 결과 공간 | 두 화면 같은 승자, 자유 조작 | |
| 8 | 결과 공간 한 명만 준비 → 둘 다 준비 | 기다림 → 같은 방 새 경기 | |
| 9 | 결과 공간 또는 로비에서 한 명 X | 누른 쪽 바로 메인, 다른 쪽 "연결 종료"와 이유 뒤 메인 | |
| 10 | 경기 중 한쪽 창 닫기/네트워크 끊기 | 남은 쪽 이유 표시 뒤 메인 | |
| 11 | 다시 방 만들기·참가 | 이전 상태가 섞이지 않음 | |

## 연출 메모 (CP7 뒤 다듬기)

| 화면 | 마음에 들지 않는 점 | 원하는 방향 |
|---|---|---|
| 결과 공간 | 승자 색과 상관없는 화면 | 승리 화면 전체를 승자 색에 맞춰 디자인 |

이미 임시로 표시해 둔 항목: 결과·로비 맵 모양, 결과 공간·로비 UI 배치·글자, 머리 위 준비 표식, 메뉴·옵션 버튼 배치, 큰 캐릭터 퇴장·시상대 상승·승자 점프의 시간·높이, 연결 종료 안내 3.5초, 친구 입장 때 B만 낙하(A가 낙하·KO 중이었으면 둘 다 낙하), 개발 빌드의 \` 도움말 글자(무기·옛 결과 조작이 남아 있음).
