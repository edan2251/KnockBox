## 남은 확인

사용자는 이전 2/4틱 빌드에서 같은 공유기·P1 유선/P2 Wi-Fi로 테스트했고 두 경우 모두 밀림을 느끼지 않았다고 보고했다. 3틱 새 빌드의 실제 두 PC 검수, 장시간/다른 인터넷 회선의 안정성은 별도로 확인한다.

모놀리스 2c(방향 수정)와 맵 편집기 비석·원근 보정·보상 맵 통합은 사용자 Play 확인이 남았다.
- 확인 순서: **연습 → O/P 테스트 KO로 세트 패배 → 마우스·좌우 키로 호버 → 모놀리스 클릭 → 다음 라운드**. P1·P2 패배를 모두 본다.
- 온라인에서는 패자가 호버할 때 승자 화면에도 같은 점등·어두워짐·시선이 약간 늦게 따라오는지 본다(광원은 고정). 이것은 두 PC 확인에 포함한다.
- 실제 Photon 두 Runner 호버 검사는 `-onlinebot`으로 `FusionPredictionPlayTests.RealHostClient_CardHoverTravelsBothWays…`를 실행해 확인한다.
- "윗부분 띠"는 1920×1080 실시간 캡처에서 재현하지 못했다. 다시 보이면 그 화면을 캡처해 알려 주어야 한다.

검사 불안정성 두 가지는 이번 변경 전부터 있던 것으로 판단하며, 검사는 수정하지 않았다.
