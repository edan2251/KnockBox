  - 기획서·PROGRESS를 이 방향으로 고친다. 3단계(진입 연출)부터는 Play 확인 뒤 따로 승인한다.
  - 승자도 같은 화면을 보도록 패자 호버를 표시 전용으로 전달한다. 2026-11-13 제안한 방식(비신뢰 RPC, 0.25초 반복, 0.75초 만료, `-hover1` 버전 표시)을 승인받아 구현했다.
  - 디자인 값은 프리팹과 보상 맵 장면 값(MapAuthoring)으로 노출한다(2026-11-14 보상 맵 통합 승인).
  - 3단계(진입 연출)는 2026-11-14 승인. 모든 연출에 이징을 쓰고 상황에 따라 오버슈트·찌그러짐/늘어남을 쓴다. 4단계(확정 연출)는 별도 승인.
- **결정:**
  - 확정 연출은 처음에 `PickHoldTicks` 84틱 안에 압축했다. 2026-11-14 사용자가 4b(144틱으로 연장, 예전 기록 설정 후보 유지, 온라인 버전 표시 `-hold144`)를 승인했다.
  - 승자도 패자와 같은 화면을 보며, 호버는 표시 전용으로 전달한다(시뮬레이션 입력·상태·기록·체크섬 제외).
  - 글자는 월드 공간 uGUI Text, 아이콘은 도형 조합이다.
  - 카드 문구는 임시 표시가 있는 시험 문구를 쓴다.
  - 수십 종에서 3장 뽑기는 제외한다.
  - 효과음 추가와 기존 카드 UI 제거는 Play 확인 뒤 별도 승인한다.
- **조건:**
  - 기존 카드 UI는 토글로 남긴다.
  - 시뮬레이션(`PickHoldTicks`·난수·상태 체크섬·입력 형식)을 바꾸지 않는다. 예외: 2026-11-14 승인된 4b의 `PickHoldTicks` 연장(새 경기만).
  - 상태는 확정 월드에서 읽는다.
  - 스테이징·커밋·푸시, 패키지·에셋 설치, asmdef 변경, 브랜치 전환은 하지 않는다.
- 이전 Fusion 3틱 구현·문서 정리는 완료 상태다. 실제 두 PC 검수는 사용자가 맡는다.

## 남은 확인

사용자는 이전 2/4틱 빌드에서 같은 공유기·P1 유선/P2 Wi-Fi로 테스트했고 두 경우 모두 밀림을 느끼지 않았다고 보고했다. 3틱 빌드 첫 두 PC 확인(2026-11-17)에서 P2 화면 끊김이 나와 0틱으로 바꿨다. **0틱 새 빌드 두 PC 확인(2026-11-17, 사용자): P2 화면이 이전보다 확실히 부드러워졌다.** 아직 따로 보고되지 않은 항목: 상대 위치가 튀는 보정이 거슬리는지, 타격 효과가 접촉보다 늦게 느껴지는지, 역할 교환(P2 PC가 방 만들기), 서로 다른 FPS, 다른 회선·장시간. 개발 빌드는 종료 때 `Replays/Network/online_frames_P*`·`online_inputs_P*`를 남긴다.

모놀리스 2c(방향 수정)와 맵 편집기 비석·원근 보정·보상 맵 통합은 사용자 Play 확인이 남았다.
- 확인 순서: **연습 → O/P 테스트 KO로 세트 패배 → 마우스·좌우 키로 호버 → 모놀리스 클릭 → 다음 라운드**. P1·P2 패배를 모두 본다.
- 온라인에서는 패자가 호버할 때 승자 화면에도 같은 점등·어두워짐·시선이 약간 늦게 따라오는지 본다(광원은 고정). 이것은 두 PC 확인에 포함한다.
- 실제 Photon 두 Runner 호버 검사는 `-onlinebot`으로 `FusionPredictionPlayTests.RealHostClient_CardHoverTravelsBothWays…`를 실행해 확인한다.
- "윗부분 띠"는 1920×1080 실시간 캡처에서 재현하지 못했다. 다시 보이면 그 화면을 캡처해 알려 주어야 한다.

검사 불안정성 두 가지는 이번 변경 전부터 있던 것으로 판단하며, 검사는 수정하지 않았다.
- `FrontendFlowTests.CheatKeysKillEachPlayer_ControlKeysKeepPauseAndStep`: 2b 변경 전 기준 실행에서 한 번 실패했고, 단독 실행과 변경 후 묶음 실행에서는 통과했다.
- `PresentationTests.FrameTimeAndPresentationAllocations`: 평균 프레임 시간이 16.7ms를 넘어 실패한다. 2단계 때는 묶음 안에서만 실패하고(28ms, 19ms) 단독 실행은 두 번 통과했으나, 2c 뒤에는 에디터가 포커스를 잃은 상태에서 단독 실행도 두 번 실패했다(27ms, 26ms). 이 검사는 모놀리스가 없는 Sandbox에서 돌며 연출 할당은 0 B다.
- `VisualDirectionTests.MainGoIlluminatesUnshadowedBackground…`: 1라운드 맵이 기본 맵이 아니면 실패한다. 이 검사는 고정 좌표를 그림자 영역으로 가정하지만 Main은 등록 맵 순서를 무작위로 섞는다. 실패 캡처 두 장이 모두 다른 등록 맵이었다. 변경 전 상태로 대조 실행하지는 못했다.

현재 Main 카드는 보유 목록만 적용하며 실제 능력은 아직 추가하지 않았다. 능력·연출을 수정할 때는 [카드 확장 계약](../ONLINE_MULTIPLAYER.md#카드-능력과-연출-확장)을 먼저 읽는다. 보류 무기와 구 기록 보존 범위는 [미사용 기능 보존](../INACTIVE_FEATURES.md)을 따른다.
