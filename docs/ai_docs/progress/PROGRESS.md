- `PresentationTests.FrameTimeAndPresentationAllocations`: 평균 프레임 시간이 16.7ms를 넘어 실패한다. 2단계 때는 묶음 안에서만 실패하고(28ms, 19ms) 단독 실행은 두 번 통과했으나, 2c 뒤에는 에디터가 포커스를 잃은 상태에서 단독 실행도 두 번 실패했다(27ms, 26ms). 이 검사는 모놀리스가 없는 Sandbox에서 돌며 연출 할당은 0 B다.
- `VisualDirectionTests.MainGoIlluminatesUnshadowedBackground…`: 1라운드 맵이 기본 맵이 아니면 실패한다. 이 검사는 고정 좌표를 그림자 영역으로 가정하지만 Main은 등록 맵 순서를 무작위로 섞는다. 실패 캡처 두 장이 모두 다른 등록 맵이었다. 변경 전 상태로 대조 실행하지는 못했다.

현재 Main 카드는 보유 목록만 적용하며 실제 능력은 아직 추가하지 않았다. 능력·연출을 수정할 때는 [카드 확장 계약](../ONLINE_MULTIPLAYER.md#카드-능력과-연출-확장)을 먼저 읽는다. 보류 무기와 구 기록 보존 범위는 [미사용 기능 보존](../INACTIVE_FEATURES.md)을 따른다.
