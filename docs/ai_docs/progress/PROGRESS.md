# 현재 진행 현황

기준일: 2026-11-07. 작업 프로젝트는 D:/KnockBox, Unity 버전은 6000.3.23f1입니다. 현재 코드와 미확인 사항만 요약합니다. 완료된 작업 로그와 과거 요청·설계·캡처는 [외부 기록 안내](../HISTORY.md)에서 찾습니다.

## 구현 상태

- Main에 실제 UI·카메라·주요 매니저와 참조가 사전 배치되어 있습니다.
- 메인·로비·첫 VS·경기·카드 획득·결과·O/X 재대결 흐름이 있습니다.
- 현재 조작은 WASD·Space·마우스 조준, 좌클릭 탭/홀드 공격·차징, 우클릭 잡기·무기 줍기·투척입니다. Shift는 비어 있습니다.
- 라운드 2승으로 세트 1점, 세트 5점으로 경기 승리입니다. 세트 패자가 카드를 획득하며 실제 능력 효과는 보류입니다.
- 프라이팬·권총과 보유·사용·투척·벽꿍 낙하 경로가 구현되어 있습니다.
- MapAuthoring은 정의 에셋 배치·저장·등록·시험, 테마·스냅·대칭 복사를 지원합니다. GameMaps의 1~8개 맵을 기존 결정론 방식으로 사용합니다.
- Relay·락스텝 프로토콜 9, 입력 기록 v8과 과거 기록 호환 경로가 있습니다.

자세한 책임·입력·설정·맵·온라인 기준은 [현행 개발 명세](../CURRENT_DEV_SPEC.md)에 있습니다.

## 이번 문서 정리

현재 안내와 과거 증거를 분리했습니다. 옛 폼 전투·온라인 롤백 초안·CP 기록·캡처는 저장소의 현행 문서에서 제외하고 프로젝트 밖에 보존합니다. 백업과 별도 복원 사본의 파일 크기·SHA-256 확인을 통과한 뒤 과거 자료 867개를 분리했습니다. 현재 ai_docs에는 안내 8개만 남아 있습니다. 최종 기록과 복구 위치는 [외부 기록 안내](../HISTORY.md)를 확인합니다.

게임 코드·에셋·설정·패키지와 Git 스테이징은 이번 작업에서 변경하지 않았습니다. 스테이징·커밋·푸시는 사용자가 직접 합니다. 작업 시작 시 실제 Git은 첫 게임 커밋 0b3cb54가 존재하고 staged 변경은 0개였습니다. 이는 확인 시점의 기록이며 이후 사용자 작업을 덮어쓰는 기준이 아닙니다.

## 검증 구분

이번 확인은 문서 링크·파일 보존·백업 복원·코드와 명세의 대조입니다. 링크 138개에서 끊어진 연결은 없었고 문서 외 보호 파일 951개의 해시와 Git 인덱스·staged diff가 같았습니다. 새 Unity 실행·컴파일·게임 테스트·빌드는 수행하지 않았습니다.

과거 이관 기록에는 EditMode 242개·PlayMode 7개·Windows 개발 빌드와 기준 리플레이 2개의 상태 일치 결과가 있습니다. 당시 로그는 외부 보관본에 있으며 현재 변경의 새 통과 결과가 아닙니다.

## 남은 확인

- 사용자 Unity 검수: 연습·카드·결과·재대결, MapAuthoring 저장 후 시험.
- MCP 설정 창을 닫은 상태의 반복 끊김 여부. 서버 연결이 게임 실행의 필수 조건은 아닙니다.
- 기존 ProjectBrowser/ObjectListArea 계열 에디터 오류의 원인과 재현 여부.
- Editor↔Player의 과거 중간 틱 float 차이. 원인 범위를 넘어 해결됐다고 간주하지 않습니다.
- 실제 두 PC Relay 대전, 새 clone의 컴파일·실행·빌드와 서비스 접근 권한.
- 카드 실제 효과와 원·다각형 지형 판정은 별도 승인 작업입니다.
