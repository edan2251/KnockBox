# 현재 진행 현황

## 현재 상태

2026-11-13 사용자가 Fusion 기본 예측·재시뮬레이션의 SDK 입력 지연을 **3틱**으로 확정했다. 전투·SDK·송신 60Hz와 기존 UI·전투·카드 흐름·리플레이를 보존하며 일반 실행/빌드를 이 경로로 통일했다. HUD는 SDK RTT를 표시한다.

구현·정리 완료. EditMode **1,071개**, Main/Frontend PlayMode **29개**, 실제 SDK/입력 순서 **2개**를 통과했다. Windows 개발 빌드 경고 0, 전달 ZIP 329개 파일·보존 검사도 통과했다. 서버 구조·설정·코드별 책임·확장 계약은 [온라인 구현 기준](../ONLINE_MULTIPLAYER.md)을 따른다. 실제 두 Runner 검사에서는 모의 편도 90ms·손실 3%로 확정 900틱의 입력/리플레이 일치와 SDK 재실행을 확인했다. 이전 누적 작업 로그와 비교본 원문은 [보관 목록](../HISTORY.md)에서 찾는다. 이번 문서 정리에서는 게임 코드·설정·빌드를 변경하지 않았으며 문서 21개의 링크 검사와 문서 외 1,435개 파일의 해시 대조를 통과했다. 문서만 수정했으므로 Unity 검사는 반복하지 않았다.

## 현재 승인 범위

- 최신 사용자 요청: 온라인 문서를 ai_docs로 옮기고 현재 서버 구조·수정 기준을 AI가 이해하기 쉽게 정리한다. 문서에서 커밋·푸시 안내를 제거하고 제목/설명은 대화에서만 제공한다.
- 현재 PC의 기존 Fusion 이전 변경을 보존한다. SDK는 저장소에 포함하고 App ID와 meta는 제외한다. 이름 설정·새 카드 능력·연출 재설계는 후속 작업이다.
- 3틱 구현·자동 검사·빌드는 완료 상태다. 이번 변경은 문서에 한정하며 실제 두 PC 검수와 스테이징·커밋·푸시는 사용자가 맡는다.
- 새 계정·과금·Unity Cloud 설정, SDK 업그레이드, 맵/UI 재작성, 기록 호환 제거는 이번 범위에 포함하지 않는다.

## 남은 확인

사용자는 이전 2/4틱 빌드에서 같은 공유기·P1 유선/P2 Wi-Fi로 테스트했고 두 경우 모두 밀림을 느끼지 않았다고 보고했다. 3틱 새 빌드의 실제 두 PC 검수, 장시간/다른 인터넷 회선의 안정성은 별도로 확인한다.

현재 Main 카드는 보유 목록만 적용하며 실제 능력은 아직 추가하지 않았다. 능력·연출을 수정할 때는 [카드 확장 계약](../ONLINE_MULTIPLAYER.md#카드-능력과-연출-확장)을 먼저 읽는다. 보류 무기와 구 기록 보존 범위는 [미사용 기능 보존](../INACTIVE_FEATURES.md)을 따른다.
