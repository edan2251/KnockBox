# 과거 기록 보관과 복구

과거 요청·설계·결정·CP 로그·캡처·이관 목록은 현재 개발 문서와 분리했습니다. 기존 내용은 삭제 소실한 것이 아니라 아래 프로젝트 밖 보관본에 보존합니다. 다른 PC에 Git만 받아서는 이 자료가 자동 복구되지 않습니다.

## 로컬 보관 위치

`D:/BrawlGame/Backups/DocsCurrent_20261107_01/History/docs/ai_docs/`

분리 직전 ai_docs 전체를 이전 경로 구조로 보존합니다. archive·spec·requests·progress와 이전 결정·참고 자료가 있습니다. Snapshot에는 작업 전 공유 파일 전체, RestoreCheck에는 독립 복원 확인 사본이 있습니다. 기존 백업은 덮어쓰지 않았습니다.

## 목록과 해시

같은 보관 폴더의 before.json에 작업 전 파일 크기·SHA-256과 Git 상태가 있습니다. 분리 목록은 history_manifest.csv, 최종 보존·링크·Git 검사 결과는 validation_final.json에 기록합니다. 원본 프로젝트 D:/BrawlGame/Project_Brawl과 이전 백업들도 유지합니다.

## 조회와 복구

먼저 History에서 필요한 문서를 직접 엽니다. 최신 문서에 옛 지시를 다시 적용하지 않습니다. 이관 당시 결과는 progress/migration_20261106.md, 반복 끊김은 progress/practice_perf_20261106.md, 이전 UI 요청은 requests/CR-005-ui-concepts.md에 있습니다.

과거 파일을 프로젝트에 복원하려면 현재 파일을 먼저 별도 보존하고 Snapshot 또는 History의 상대 경로와 SHA-256을 대조합니다. 전체 복원은 빈 폴더에서 확인하며, 편집 중인 게임·문서를 덮어쓰지 않습니다. 루트 AGENTS.md·CLAUDE.md를 과거 버전으로 일괄 복원하지 않습니다.

## 팀 공유와 보존 한계

이 위치는 같은 PC의 D:에 있습니다. 다른 장치의 고장까지 대비한 독립 백업은 아닙니다. 팀원이 과거 기록을 필요로 하면 보관본을 별도 공유 저장소나 외장 장치에 복사하고 해시를 대조합니다. 현재는 원격 보관소 업로드를 수행하지 않았습니다.

과거 캡처는 자체 게임 검증 증거입니다. 외부 게임 레퍼런스·LocalOnly·개인 녹화의 공개 허용을 뜻하지 않습니다. 이 자료를 다시 Git에 추가할 때에도 목적과 용량·권리·개인정보를 확인합니다.

## 이번 분리 결과

2026-11-07 작업 전 공유 파일 1,836개, 123,315,301바이트를 Snapshot과 빈 RestoreCheck에 보존해 해시를 대조했습니다. 분리 전 ai_docs 전체 873개는 History와 별도 HistoryRestoreCheck에서 모두 SHA-256이 같았습니다. 과거 자료 867개는 프로젝트 밖으로 이동했고 현재 ai_docs에는 안내 8개만 남겼습니다.

현재 문서 링크 138개가 정상입니다. 게임 코드·에셋·설정·패키지 등을 포함한 보호 파일 951개의 내용은 같고 Git HEAD·인덱스·staged diff도 그대로입니다. Unity 실행·게임 테스트·새 빌드는 수행하지 않았습니다. 최종 상세 결과는 이 보관 폴더의 validation_final.json에 있습니다.

## 코드 주석의 옛 문서 표기

코드 주석의 `01-architecture.md`, `03-combat.md`, `09-props-physics.md` 같은 번호 문서, `CR-002`~`CR-005`, "08 5절" 같은 표기는 이관 전 Project_Brawl의 명세·요청서를 가리킵니다. 저장소에는 없고 위 로컬 보관 위치의 `spec/`, `requests/`에 있습니다. 현재 동작은 [현행 개발 명세](CURRENT_DEV_SPEC.md)와 코드를 기준으로 합니다.

코드 주석의 `CP1`~`CP23`(예: "CP4 Shift 차징", "CP16 부분 붕괴")은 옛 프로젝트의 체크포인트 번호입니다. 현재 [맵 제작기 계획](MAP_AUTHORING_PLAN.md)의 CP1~CP5와 번호가 겹치지만 다른 작업입니다. 맵 제작기 작업 주석은 기능 이름이나 `MapAuthoring`, `Validation/CP5_*` 같은 파일명으로 구분합니다.
