## 보관과 문서 관리

[과거 기록 보관](ai_docs/HISTORY.md)

프로젝트 밖에 보존한 과거 기록과 캡처의 위치·목록·해시·복구 절차입니다. Git 사본만으로 복구되는 자료가 아니므로 별도 관리합니다.

사용법은 team의 해당 문서를 보완합니다. 현재 구현이 바뀌면 현행 개발 명세와 PROGRESS를 갱신합니다. 같은 규칙을 여러 파일에 복제하지 않고 WORKING_RULES와 COMMIT_RULES를 참조합니다.

새 기록은 필요한 결과·실패·미확인만 짧게 남깁니다. 완료된 큰 로그·캡처는 별도 보관 정책을 따릅니다. 제목은 짧은 명사형, 목록은 제목·링크 다음에 설명을 붙입니다.
