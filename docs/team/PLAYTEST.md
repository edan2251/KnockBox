## 1. 연습 모드 실행

[Main 씬](../../Assets/_Project/Scenes/Main.unity)을 열고 Play를 누른 뒤 연습 모드로 들어갑니다. Game 창을 클릭해 입력을 받도록 합니다. 처음 여는 PC의 준비 절차는 [프로젝트 열기](SETUP.md)에 있습니다.


이동 / 점프

현재 마우스·키보드 조작: WASD / Space


조준

현재 마우스·키보드 조작: 마우스 이동


기본 공격 / 무기 사용

현재 마우스·키보드 조작: 마우스 왼쪽을 짧게 눌렀다 놓기


차징 몸통 박치기

현재 마우스·키보드 조작: 왼쪽을 길게 누른 뒤 놓기. 충분히 모으지 않으면 돌진하지 않습니다.


상대 잡기 / 무기 줍기·던지기

현재 마우스·키보드 조작: 마우스 오른쪽. 잡은 상대는 왼쪽 공격으로 던집니다.


Shift

현재 마우스·키보드 조작: 현재 Brawl 조작에서는 사용하지 않습니다.


연습 메뉴

현재 마우스·키보드 조작: Esc


위 표는 현재 `MouseAimInputSource`의 조작입니다. 옛 키보드 2인·폼 전투 안내나 리플레이 호환 입력과 혼동하지 마세요. 실제 코드 위치는 [입력 소스](../../Assets/_Project/Scripts/Game/Input/MouseAimInputSource.cs)입니다.

## 2. 한 경기에서 볼 것

1. **시작:** 최초 VS 화면이 한 번 나오고, 경기장이 구성된 뒤 3·2·1·GO로 시작하는지 봅니다. 다음 라운드마다 VS가 다시 나오는 흐름은 아닙니다.
2. **전투:** 이동·점프·조준·짧은 공격·차징과 무기 줍기·사용·던지기를 확인합니다. 끊김은 발생 시점과 반복 간격을 적습니다.
3. **득점:** 라운드 2승으로 세트 1점을 얻는지 봅니다. 경기 중 점수와 두 작은 라운드 점의 연출을 함께 확인합니다.
4. **카드:** 최종 세트가 아니라면 세트 패자가 카드를 고릅니다. 마우스 호버와 클릭, 획득 목록, 다음 라운드 진행을 확인합니다. 현재 카드 능력 효과의 실제 적용은 보류 상태입니다.
5. **결과:** 세트 5점으로 경기가 끝나는지 봅니다. 다시하기 O를 누른 쪽이 밝아지고 준비가 표시되는지, X로 나갈 수 있는지 확인합니다. 연습 모드에서는 자신의 O 이후 짧은 확인 시간을 거쳐 재시작합니다.

화면 모양의 세부 검수는 [아트 안내](ART_WORKFLOW.md), 여러 맵의 등록·시험은 [팀 안내](TEAM_WORKFLOW.md)를 사용합니다. 새로운 맵에서 같은 모양이라도 정의 ID가 다르면 맵 순환에서는 다른 맵으로 취급될 수 있습니다.

## 3. 빠르게 화면을 확인하는 단축키

Unity 에디터와 개발 빌드의 **로컬 전투 중**에는 O로 P1, P로 P2를 즉사시킬 수 있습니다. 결과 화면의 O 버튼과 키보드 O는 별개입니다. 온라인·녹화·리플레이·동기화 시험 중에는 이 즉사 기능을 막습니다.

Ctrl+P는 일시정지, Ctrl+O는 정지 중 한 틱 진행입니다. 키를 누른 시점에 Game 창이 입력을 받고 있는지도 확인하세요. 구현은 [DebugHotkeys](../../Assets/_Project/Scripts/Game/Debug/DebugHotkeys.cs)와 [MatchRunner](../../Assets/_Project/Scripts/Game/Bootstrap/MatchRunner.cs)에 있습니다.

## 4. 문제를 전달할 때

어느 씬·모드에서 어떤 버튼을 눌렀는지, 기대한 결과와 실제 결과가 무엇인지 적습니다. 가능하면 다시 발생시키는 짧은 순서와 Console의 첫 오류를 함께 전달하세요. 끊김은 MCP 설정 창·Profiler가 열려 있었는지와 서버 연결 여부도 구분하면 도움이 됩니다.

이번 확인 범위는 로컬 연습입니다. 두 PC Relay 실기 보류 등 검증 범위는 [작업 규칙](../ai_docs/WORKING_RULES.md#검증과-보고)을 따릅니다. 자동 검사 통과와 사람이 느끼는 조작감은 별도로 기록합니다.
