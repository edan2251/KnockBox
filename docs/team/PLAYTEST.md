# 현재 게임을 직접 확인하는 방법

Main 씬의 로컬 연습과 맵 제작기 회귀 검수 절차입니다. 실제 최신 실행 결과는 [진행 현황](../ai_docs/progress/PROGRESS.md), 온라인 접속 순서는 [Photon 설정](../ai_docs/ONLINE_MULTIPLAYER.md#기본-접속과-새-pc-설정)을 봅니다. 이 문서는 확인할 절차이며 모든 항목의 통과를 선언하지 않습니다.

<a id="1-연습-모드-시작하기"></a>

## 1. 연습 모드 실행

[Main 씬](../../Assets/_Project/Scenes/Main.unity)을 열고 Play를 누른 뒤 연습 모드로 들어갑니다. Game 창을 클릭해 입력을 받도록 합니다. 처음 여는 PC의 준비 절차는 [프로젝트 열기](SETUP.md)에 있습니다.


이동 / 점프

현재 마우스·키보드 조작: WASD / Space


조준

현재 마우스·키보드 조작: 마우스 이동


기본 펀치

현재 마우스·키보드 조작: 마우스 왼쪽을 짧게 눌렀다 놓기


차징 몸통 박치기

현재 마우스·키보드 조작: 왼쪽을 길게 누른 뒤 놓기. 충분히 모으지 않으면 돌진하지 않습니다.


상대 잡기 / 던지기

현재 마우스·키보드 조작: 마우스 오른쪽. 잡은 상대는 왼쪽 공격으로 던집니다.


Shift

현재 마우스·키보드 조작: 현재 Brawl 조작에서는 사용하지 않습니다.


연습 메뉴

현재 마우스·키보드 조작: Esc


위 목록은 현재 `MouseAimInputSource`의 조작입니다. 옛 키보드 2인 안내나 리플레이 호환 입력과 혼동하지 마세요(폼 전투는 2026-11-11 삭제). 실제 코드 위치는 [입력 소스](../../Assets/_Project/Scripts/Game/Input/MouseAimInputSource.cs)입니다.

## 2. 한 경기에서 볼 것

1. **시작:** 최초 VS 화면이 한 번 나오고, 경기장이 구성된 뒤 3·2·1·GO로 시작하는지 봅니다. 다음 라운드마다 VS가 다시 나오는 흐름은 아닙니다.
2. **전투:** 이동·점프·조준·짧은 펀치·차징과 상대 잡기·던지기를 확인합니다. 현재 무기·총알은 보류하여 나오지 않아야 합니다. 끊김은 발생 시점과 반복 간격을 적습니다.
3. **득점:** 라운드 2승으로 세트 1점을 얻는지 봅니다. 경기 중 점수와 두 작은 라운드 점의 연출을 함께 확인합니다.
4. **카드:** 최종 세트가 아니라면 세트 패자가 카드를 고릅니다. 마우스 호버와 클릭, 획득 목록, 다음 라운드 진행을 확인합니다. 현재 카드 능력 효과의 실제 적용은 보류 상태입니다.
5. **결과:** 세트 5점으로 경기가 끝나는지 봅니다. 다시하기 O를 누른 쪽이 밝아지고 준비가 표시되는지, X로 나갈 수 있는지 확인합니다. 연습 모드에서는 자신의 O 이후 짧은 확인 시간을 거쳐 재시작합니다.

화면 모양의 세부 검수는 [아트 안내](ART_WORKFLOW.md), 여러 맵의 등록·시험은 [팀 안내](TEAM_WORKFLOW.md)를 사용합니다. 새로운 맵에서 같은 모양이라도 정의 ID가 다르면 맵 순환에서는 다른 맵으로 취급될 수 있습니다.

## 3. 빠르게 화면을 확인하는 단축키

Unity 에디터와 개발 빌드의 **로컬 전투 중**에는 O로 P1, P로 P2를 즉사시킬 수 있습니다. 결과 화면의 O 버튼과 키보드 O는 별개입니다. 온라인·녹화·리플레이·동기화 시험 중에는 이 즉사 기능을 막습니다.

Ctrl+P는 일시정지, Ctrl+O는 정지 중 한 틱 진행입니다. 키를 누른 시점에 Game 창이 입력을 받고 있는지도 확인하세요. 구현은 [DebugHotkeys](../../Assets/_Project/Scripts/Game/Debug/DebugHotkeys.cs)와 [MatchRunner](../../Assets/_Project/Scripts/Game/Bootstrap/MatchRunner.cs)에 있습니다.

## 4. 문제 전달

어느 씬·모드에서 어떤 버튼을 눌렀는지, 기대한 결과와 실제 결과가 무엇인지 적습니다. 가능하면 다시 발생시키는 짧은 순서와 Console의 첫 오류를 함께 전달하세요. 끊김은 MCP 설정 창·Profiler가 열려 있었는지와 서버 연결 여부도 구분하면 도움이 됩니다.

이 절의 확인 범위는 로컬 연습입니다. 두 PC Fusion 확인은 [Photon 설정](../ai_docs/ONLINE_MULTIPLAYER.md#기본-접속과-새-pc-설정)의 접속·실패 시나리오로 구분하며, 자동 검사 통과와 사람이 느끼는 조작감은 별도로 기록합니다.


## 5. CP3·CP4 최초 당김 로프와 절단 검수

아래 로프 항목은 기존 당김 시험 맵의 호환 확인용입니다. 현재 공격 연결부 검수는 6절을 사용합니다.

자동 검증 결과는 [PROGRESS](../ai_docs/progress/PROGRESS.md), 버튼과 저장 절차는 [팀 안내](TEAM_WORKFLOW.md#독립-로프)에 있습니다. 아래는 사용자가 직접 확인할 항목입니다.

1. **현재 편집 보존:** MapAuthoring의 기존 작업을 먼저 저장합니다. Definition에서 시험 맵을 선택한 뒤 **맵 불러오기**를 사용합니다. GameMaps에는 등록할 필요가 없습니다.
2. **로프:** `CP3_Rope_Pull`에서 상자를 가볍게 밀거나 짧게 펀치한 뒤 초기화합니다. 오른쪽으로 충분히 차징해 부딪쳤을 때 팽팽한 줄이 끊어지고 상자가 속도·회전을 이어가는지 봅니다. `CP3_Rope_Fixed`에서 같은 입력을 줘도 줄이 유지되는지 비교합니다. 약한 충격의 방향·횟수에 따라 힘이 쌓인 속도는 달라질 수 있습니다.
3. **연결 편집:** 물리 상자에 로프를 추가하고 고정점·연결점·길이를 조절합니다. 상자와 함께 복제/좌우 대칭한 뒤 새 로프가 새 상자를 가리키는지, 저장·재열기 후 유지되는지 확인합니다.
4. **절단:** `CP4_Cut_Rope_Trial`의 중앙 사각형에서 윗변 중간과 오른쪽 변 중간을 선택합니다. 유지/제거 영역, 반대편 선택, 취소, 적용과 한 번 Undo, 반복 절단을 확인합니다.
5. **경기 표시와 접촉:** 저장·재열기 후 **저장한 맵으로 시험**을 실행합니다. 사선의 보이는 면에 캐릭터·상자가 닿고 잘려 나간 부분은 통과하는지, 그림자가 남은 모양을 따르는지 봅니다. 기존 적층과 회색 기둥의 플레이어 통과도 함께 확인합니다.
6. **복귀:** Play 중지 또는 **Knockbox → 맵 → 시험 종료 및 편집 복귀**로 제작기로 돌아옵니다.

사용자가 2026-11-11 제작기 CP5 Unity 검수 완료를 승인했습니다. 위 절차는 기존 로프·절단의 회귀 확인용이며 최신 빌드·온라인 검증 여부는 진행 현황을 따릅니다.

## 과거 안내

최초 설치·CP24 폼 전투 안내는 [외부 보관본](../ai_docs/HISTORY.md)에 있습니다. 현재 실행 절차나 조작으로 적용하지 않습니다.


## 6. 공격으로 부서지는 로프 연결부

이 절은 이전 비고체 연결부 방식의 기록입니다. 현재 독립 연결 상자와 여러 줄 연결은 아래 7절에서 확인합니다.

1. 현재 편집한 맵과 씬을 저장합니다. MapAuthoring의 **편집할 맵**에 `Assets/_Project/Data/Maps/Validation/CP3_Rope_Connector_Trial.asset`을 넣고 **맵 불러오기 → 저장한 맵으로 시험**을 누릅니다. GameMaps 등록은 필요 없습니다. 시험 후 Play를 끝내 제작기로 돌아옵니다.
2. 왼쪽 줄은 **일반 로프**, 오른쪽 줄은 **공격 연결부**입니다. 오른쪽 연결부는 (5, -5.2) 부근의 밝은 사각 표시이며 그 옆 발판에 두 플레이어가 시작합니다. 일반 줄은 상자를 밀거나 충격을 줘도 유지돼야 합니다.
3. 오른쪽 발판 끝에서 연결부 쪽으로 걷거나 점프합니다. 이 동작만으로 연결부가 부서지거나 몸이 막히면 안 됩니다. 이어서 연결부를 향해 좌클릭을 짧게 눌렀다 떼 펀치합니다. 실제 주먹이 맞으면 사각 표시와 줄이 사라지고 상자가 떨어져야 합니다.
4. 시험을 다시 시작해 초기 배치를 복원합니다. 연결부 쪽으로 충분히 좌클릭 차징 후 해제합니다. 연결부를 지나가며 속도가 한 번 15% 줄고 벽꿍·추가 피해가 없어야 합니다. 상자 본체나 다른 실제 지형에 닿으면 그 대상의 기존 충돌은 적용됩니다.
5. 다시 초기화하고 상대를 우클릭으로 잡은 다음 연결부를 향해 좌클릭으로 던집니다. 던져진 플레이어가 연결부를 부수고 감속하며 통과하는지 봅니다. 일반 펀치에 밀려난 피격 경직은 던져진 상태와 다릅니다.
6. 제작기로 돌아와 `Ropes/Rope_1`의 **관통 감속 (%)**를 조정하고 **맵 저장 → 맵 불러오기 → 저장한 맵으로 시험**으로 유지 여부와 손맛을 비교합니다. 0%는 속도 유지, 15%는 속도 85% 유지, 100%는 파괴 순간 정지입니다. 원래 비교 맵을 보존하려면 먼저 **현재 배치를 새 사본으로 저장**를 사용합니다.

자동 검사와 별개로 사람이 확인할 부분은 연결부의 눈에 띄는 정도, 주먹이 닿는 느낌, 차징/던지기의 15% 감속 체감과 낙하 연출입니다. 기존 맵은 자동 변환하지 않았으므로 기존 로프에서 새 동작을 쓰려면 **로프 종류**를 명시적으로 변경해야 합니다.

## 7. 상자 연결망과 독립 연결 상자

현재 작업 맵과 씬을 먼저 저장합니다. 아래 시험 정의를 MapAuthoring의 **편집할 맵**에 넣고 **맵 불러오기 → 저장한 맵으로 시험**을 누릅니다. 시험 정의 원본을 바꾸려면 먼저 사본을 만듭니다. GameMaps 등록은 필요 없습니다. 각 공격은 Play를 종료하고 다시 시험해 초기 상태에서 비교합니다.

**[CP3_Rope_Graph_Trial.asset](../../Assets/_Project/Data/Maps/Validation/CP3_Rope_Graph_Trial.asset)**

- 왼쪽: 천장 → 상자 → 긴 발판 → 상자가 이어집니다. 물리 상자끼리 연결점이 따라 움직이고, 공격이나 하중만으로 일반 줄이 끊어지지 않는지 봅니다.
- 오른쪽: 세 개의 밝은 아웃라인 상자가 넓은 발판을 여러 줄로 지지합니다. 발판 밑의 두 상자를 발판 삼아 올라가거나 점프해 접근합니다.
- 왼쪽 `(3, -3)`·가운데 `(6, -2)`·오른쪽 `(9, -3)` 연결 상자의 중앙과 가장자리에 올라서서 약 15초 기다리고 점프·착지를 비교합니다. 가만히 밟기만 해서 체력이 줄거나 지속적으로 고속 떨림이 나거나 상자가 파괴되면 안 됩니다. 한쪽 끝을 밟아 정상적으로 기울고 미끄러져 내려오는 것은 고정 조인트 없이 남겨 둔 동작입니다.
- 왼쪽 연결 상자 `(3, -3)`에 펀치를 맞힙니다. 테두리가 잠깐 밝아진 뒤 조각으로 갈라지고, 바로 붙은 두 줄만 짧게 되감기며 사라져야 합니다. 다른 지지줄은 남아야 합니다.
- 가운데·오른쪽 연결 상자도 파괴하면 발판이 떨어집니다. 발판과 아래 상자 사이의 줄은 남고 몸체의 속도·회전이 이어져야 합니다.

**[CP3_Connector_Body_Trial.asset](../../Assets/_Project/Data/Maps/Validation/CP3_Connector_Body_Trial.asset)**

- 시작 발판 오른쪽 `(0, 3)`의 아웃라인 상자가 대상입니다. 근처에서 짧은 좌클릭 펀치를 맞혀 파괴를 확인합니다.
- 초기화 후 그쪽으로 충분히 좌클릭 차징하고 놓습니다. 연결 상자에 즉시 막히거나 벽꿍하지 않고 뚫고 지나가며 약간 감속해야 합니다.
- 초기화 후 가까운 상대를 우클릭으로 잡고 연결 상자 쪽을 향해 좌클릭으로 던집니다. 던져진 몸도 파괴·감속·관통해야 합니다. 다른 지형이나 남은 일반 상자의 충돌은 유지됩니다.
- 제작기로 돌아와 연결 상자의 **관통 감속 (%)**를 15에서 0이나 30으로 바꾸고 **맵 저장 → 맵 불러오기 → 시험**으로 차이를 확인합니다.

**접촉과 파괴 연출**

일반 이동으로 부딪칠 때는 작은 테두리 반응·접촉음, 펀치·차징·던진 몸으로 파괴할 때는 더 선명한 섬광·테두리 파편·파열음·화면과 광원 흔들림을 비교합니다. 가만히 올라선 동안 효과음이나 화면 흔들림이 계속 반복되지 않는지도 봅니다. 실제로 빠르게 날아오는 상자에 옆으로 맞을 때의 기존 피해는 유지됩니다. 현재 파괴 연출은 공격한 캐릭터의 짧은 몸 반동, 방향성 화면 반동과 확대, 테두리 섬광/파편을 함께 사용합니다. 먼저 같은 맵에서 짧은 좌클릭 펀치로 확인한 뒤 차징·던지기와 비교합니다. MatchPresenter의 **연결 상자 타격 강조**는 기본 1이며 0.5~2로 화면 반동·확대·흔들림을 조절합니다. F7이 켜져 있으면 반동·확대가 30%로 줄어듭니다. 효과가 너무 크거나 약한지, 파편이 사라지는 속도가 자연스러운지도 알려주세요.

**편집 검수**

물리 상자 두 개 선택 → **선택한 상자 2개 연결** → 시작/끝 상자 연결점 이동 → 다른 줄 추가 → 함께 선택해 복제 또는 대칭 → Undo/Redo → 맵 저장/재열기 순서로 봅니다. 양끝 참조가 복사본을 향하는지 Inspector에서 확인합니다. 상자 하나만 복사하면 선택하지 않은 원본과 연결되는 줄은 복사하지 않는 규칙입니다.

자동 검사 대상은 결정론적 물리·저장·참조·입력·리플레이·통신 지연 재현입니다. 실제 화면의 줄/아웃라인 가독성, 흔들림과 15% 감속의 손맛, Play에서 편집기 복귀는 사용자 검수 항목입니다. 실제 실행한 검사와 빌드는 진행 현황에 남깁니다. ROUNDS의 내부 연결/파단 규칙을 동일하게 재현했다는 뜻은 아닙니다.
