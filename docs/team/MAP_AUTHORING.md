# 맵 제작 사용 안내

제작기와 각 오브젝트 Inspector의 **맵 제작 사용 안내 / 맵 제작기로 · 저장 / 시험 / 추가** 버튼을 시작점으로 사용합니다. 실행 오브젝트는 영문 이름이며 편집 버튼은 한글입니다. 전체 팀 작업 원칙은 [팀 안내](TEAM_WORKFLOW.md)를 따릅니다.

## 빠른 순서

1. **맵 파일**에서 정의를 고르고 **맵 불러오기**를 누릅니다. 원본을 남기려면 **현재 배치를 새 사본으로 저장**으로 시작합니다.
2. **오브젝트 추가**에서 필요한 종류를 생성하고 Scene 뷰에서 위치와 크기를 바꿉니다.
3. Hierarchy에서 오브젝트를 선택해 전용 Inspector의 절단·질량·연결·복제 버튼을 사용합니다.
4. **맵 제작기로 · 저장 / 시험 / 추가 → 맵 저장 → 저장한 맵으로 시험** 순서로 확인합니다. 등록은 필요 없습니다.
5. Play를 중지하면 편집으로 돌아옵니다. 실전 맵으로 사용할 때만 **정식 경기 목록 · 별도 등록**을 펼칩니다.

## 생성 종류

**고정 사각 지형**

움직이지 않는 땅입니다. 선택 후 **두 점 절단 시작**으로 모서리를 깎습니다. 상자처럼 밀리거나 회전하지 않습니다.

**물리 상자**

플레이어가 밟거나 밀 수 있으며 다른 상자·지형과 부딪힙니다. 크기와 질량은 별도 값입니다.

**긴 기둥 · 플레이어 통과**

긴 물리 상자 프리셋입니다. 플레이어만 통과하고 다른 상자·지형과는 충돌합니다. 별도 기둥 물리나 고정 조인트는 없습니다.

**연결 상자 · 공격 시 파괴**

일반 물리 상자처럼 밟을 수 있습니다. 펀치·차징·던져진 플레이어에 파괴되면 이 상자에 직접 연결된 로프만 풀립니다. 로프의 종류가 아니라 독립된 상자입니다.

**일반 로프**

상자 하나 선택 → **고정점 → 이 상자 연결**. 상자 두 개 선택 → **선택한 상자 2개 연결**. 일반 줄 자체는 공격·무게로 끊어지지 않습니다.

## 맵 파일과 오브젝트

기존 전투 규칙과 Brawl 원본 판정은 유지합니다. 일반 Main 경기는 GameMaps에 등록된 목록을 순환합니다.

### 맵 열기·배치·저장

1. [MapAuthoring 씬](../../Assets/_Project/Scenes/MapAuthoring.unity)을 엽니다. `Map_Authoring___definition_is_source`의 `MapAuthoring` 컴포넌트에서 편집할 맵과 정식 경기 목록의 GameMaps를 확인합니다.
2. `BrawlTrial`은 원본과 같은 별도 사본이라 새 작업의 출발점으로 사용할 수 있습니다. 씬에 연결된 편집할 맵은 작업마다 달라질 수 있으므로 먼저 확인하세요. **`BrawlOriginal`은 덮어쓰지 않습니다.** 새 맵은 `현재 배치를 새 사본으로 저장`으로 만들고 기존 경로를 덮어쓰지 않습니다.
3. `맵 불러오기`로 정의의 지형과 시작 위치를 씬에 펼칩니다.
4. `Terrain___explicit_box_order` 아래 상자의 Transform **XY 위치와 XY Scale**을 편집합니다. 위치는 중심, Scale은 폭·높이입니다. 시작 마커는 캐릭터의 **발바닥 위치**입니다.
5. 상자가 더 필요하면 `고정 사각 지형 추가`를 사용합니다.
6. `맵 저장`으로 편집 중인 정의에 저장합니다. **씬 저장만으로는 게임 맵이 바뀌지 않습니다.** 다시 불러와 저장 내용을 확인합니다.

미저장 배치나 잘못된 설정이 있으면 Inspector 상단에서 실제 원인을 알려주며 등록·시험을 막습니다. **씬 저장(Ctrl+S)과 맵 저장은 별개**입니다. 저장이 실패했을 때는 위쪽 오류를 먼저 확인합니다. 로프 길이가 부족하면 **짧은 로프만 길이 맞추기 → 맵 저장**으로 진행합니다. 이 버튼은 짧은 줄만 현재 두 점 거리로 늘리며 위치와 충분히 긴 줄은 유지하고 한 번 Undo를 지원합니다. 다른 유효성 오류를 무시하지 않습니다.

### 오류로 처리되는 배치

- 회전, Z 변형, 음수 크기
- 중복된 ID 또는 Order
- 맵 범위 밖이거나 지형에 겹치는 시작 위치
- 등록되지 않은 자식 오브젝트

Hierarchy의 표시 순서와 실제 판정 순서는 별개입니다. Order는 **0부터 빈틈없이** 이어져야 합니다.

**도형 순서 정리**는 제작기 설정과 각 도형 Inspector에 있습니다. 중간 도형을 Hierarchy에서 삭제한 뒤 눌러 번호의 빈칸을 메웁니다. 고정 지형과 물리 상자를 각각 기존 번호 순으로 정리하며, 같은 번호끼리만 Hierarchy 순서를 따릅니다. 위치·크기·질량·ID는 유지하고 한 번의 Undo/Redo를 지원합니다. 정리 후 **맵 저장**으로 게임에 반영합니다. 회전·잘못된 스폰·중복 ID 같은 다른 오류는 이 버튼으로 숨기지 않습니다.

고정 지형 이름은 `Terrain_Box_0`, `Terrain_Box_1`처럼 표시합니다. 물리 상자는 `Physics_Box_0` 형식이며 긴 기둥도 같은 규칙입니다. 내부 고유 ID는 그대로 유지합니다. 등록용 ID와 Order는 세션·기록 식별과 충돌 순서에 영향을 주므로, 출시된 맵은 사본으로 수정하는 편을 권장합니다.

### 물리 상자

`고정 사각 지형 추가`는 움직이지 않는 땅이고, **물리 상자 추가**는 밀리거나 회전하고 떨어지는 상자입니다.

1. **오브젝트 추가**에서 `물리 상자 추가`, `긴 기둥 추가 · 플레이어 통과`, `연결 상자 추가 · 공격 시 파괴` 중 필요한 버튼을 누릅니다. `Physical_Boxes` 아래 `Physics_Box_0`처럼 생성됩니다. 기본 상자는 1.5×1.5·질량 2.25, 긴 기둥은 1.5×4·질량 4로 시작합니다. 기둥은 플레이어만 통과하며 `#222222 / 알파 130`으로 표시합니다. 상자·기둥·지형끼리는 기존 물리로 충돌합니다.
2. 상자의 Transform XY 위치·Scale을 조정합니다. 물리 상자 컴포넌트의 **질량**은 크기와 별개입니다. 크기를 바꿔도 질량은 유지됩니다. **역할**을 `플레이어 통과 기둥`으로 바꾸면 플레이어는 걷기·점프·돌진 모두 통과하며 직접 밀거나 밟을 수 없습니다. 기존에 배치한 긴 상자도 이 설정을 켠 뒤 맵 저장하면 변환됩니다. 크기만 보고 자동 변환하지 않습니다.
3. **위로 복제 · 연결 로프 포함**는 선택 묶음 높이만큼 위에 같은 상자를 만듭니다. **좌우 대칭 복사 · 연결 로프 포함**는 x=0 반대편에 만듭니다. 여러 개 선택과 한 번의 Undo/Redo를 지원합니다. 통과 설정도 복사됩니다.
4. 전용 복제·삭제 버튼은 새 ID와 연속 번호를 관리합니다. Hierarchy에서 직접 삭제했으면 **도형 순서 정리**로 복구합니다. 일반 Ctrl+D는 ID까지 복사하므로 복제에는 전용 버튼을 사용합니다. 번호 정리는 기존 ID를 새로 만들지 않습니다.
5. **맵 저장 → 맵 불러오기 → 저장한 맵으로 시험**으로 확인합니다. GameMaps 등록은 별도입니다.

**상자 밑면을 윗면에 맞춤**은 켜고 끌 수 있습니다. 아래쪽 면이 가까운 고정 지형 또는 다른 상자의 윗면에 붙습니다. 기본 인식 거리 0.6이며 격자 스냅 후 적용합니다. 가로 위치는 유지하고, 다른 상자/지형에 겹치는 자리는 거절합니다. 발 위치는 일반 물리 상자 윗면에 붙일 수 있지만 통과 기둥 윗면에는 붙지 않습니다. 다른 상자를 기둥 위에 쌓는 스냅은 그대로 동작합니다.

상자 구분선은 없으며 기존 테마 색의 미세한 밝기 차로 상자를 구분합니다. 강한 충격 뒤 밀림은 `Assets/_Project/Data/Tuning/CombatTuning.asset`의 **현재 경기 상자 반응**에서 조정합니다. **점진적인 상자 밀림**이 현재 기본이며 **강한 충격 후 최소 마찰 비율**은 0.15입니다. 바닥 마찰과 상자 질량은 그대로입니다. 값을 바꾼 뒤 새 시험을 시작해 확인하며, 과거 리플레이는 기록에 맞는 설정으로 재생합니다. 미등록 맵 시험과 리플레이 한계는 아래 호환 안내를 따릅니다.

초기 회전은 0으로 배치합니다. 회전·낙하는 실제 경기의 결정론적 물리에서 일어납니다. 최대 48개, 양수 크기/질량, ID/순서, 서로 겹치는 상자, 지형·스폰과 겹침, 경기장 밖 배치를 검사합니다. 같은 크기의 가벼운 상자와 무거운 상자를 함께 비교한 뒤 질량을 정하세요.

현재 기둥 검수용 정의는 `Assets/_Project/Data/Maps/Validation/CP2_1_Pass_Through_Single.asset`과 `CP2_1_Pass_Through_Adjacent.asset`입니다. 구 `CP2_1_Single_Stack.asset`과 `CP2_1_Adjacent_Stack.asset`은 1×4·플레이어 충돌이 있는 과거 기준 맵으로 보존합니다. 첫 맵은 짧은 상자와 긴 기둥이 번갈아 놓인 4단 적층, 둘째는 같은 적층 왼쪽의 기둥을 추가한 배치입니다. GameMaps에 등록하지 않았습니다. 현재 편집을 저장한 뒤 **편집할 맵 → 맵 불러오기 → 저장한 맵으로 시험**으로 엽니다. 정지·약한 밀기·충분한 차징의 초기화 방법과 관찰 항목은 [현재 검수 절차](../ai_docs/progress/PROGRESS.md)에 있습니다. 독립 로프 제작과 고정 지형 절단은 아래 절차를 사용합니다.

### 로프 연결과 연결 상자

새 로프는 끊어지지 않는 일반 줄입니다. 색은 공통 `#555555`, 두께는 월드 0.12(기존 0.06의 두 배)입니다. 제작기와 경기에서 같은 값을 씁니다. **고정점 → 상자, 상자 → 상자, 한 상자에 여러 줄**을 지원합니다. 줄 자체는 캐릭터를 막지 않습니다. 상자 중심이나 끝 어느 곳에 붙일지는 배치 의도에 따라 정합니다. 끝에 붙이면 당김이 회전에도 영향을 줍니다.

1. 물리 상자를 선택해 **고정점 → 이 상자 연결**을 누릅니다. `Ropes/Rope_0`처럼 생성됩니다. Inspector의 **끝 상자 / 상자 안 연결점**을 확인합니다.
2. 상자끼리 잇기: Hierarchy에서 상자 두 개를 함께 선택하고 **선택한 상자 2개 연결**을 누릅니다. 또는 로프에서 **시작점도 상자에 연결**을 켜고 **시작 상자 / 시작 상자 안 연결점**을 지정합니다. 두 상자의 순서가 반대여도 물리는 같습니다.
3. 고정점 줄은 Transform을 움직입니다. 상자에 붙은 점은 Scene의 연결점 핸들이나 로컬 좌표로 움직입니다. 로컬 좌표는 상자 중심 기준 실제 길이입니다. 중심은 `(0, 0)`, 윗면 중앙은 `(0, 높이/2)`, 아랫면 중앙은 `(0, -높이/2)`입니다. Scale을 다시 곱하지 않습니다.
4. **줄 길이**는 두 점 거리 이상입니다. **현재 거리로 줄 길이 맞추기**는 팽팽하게, 더 긴 값은 느슨하게 만듭니다. 전체 배치에는 **짧은 로프만 길이 맞추기**를 사용할 수 있습니다.
5. **맵 저장 → 맵 불러오기 → 저장한 맵으로 시험**으로 확인합니다. 등록은 별도이며 미등록 시험도 Main의 실제 경기 경로를 사용합니다.

**연결 상자 추가 · 공격 시 파괴**는 별도 생성 버튼입니다. 기본 크기 0.65×0.65, 질량 0.4225, 관통 감속 15%로 시작합니다. 크기·질량·감속은 편집할 수 있습니다. 일반 상자를 선택하고 **역할**을 `공격 시 파괴되는 연결 상자`로 바꿔도 됩니다. 이 경우 기존 질량을 유지하고 감속값을 확인하세요. 역할 선택은 플레이어 통과와 연결 상자를 동시에 켜지 않도록 관리합니다.

연결 상자는 기존 아웃라인과 `#222222 / 알파 130`의 반투명 내부를 가지며 **사각형 전체가 일반 상자와 같은 충돌 몸체**입니다. 위에 서거나 점프하고, 다른 상자가 부딪혀도 파괴되지 않습니다. 펀치·차징·던져진 플레이어의 타격만 파괴합니다. 파괴 시 그 상자와 직접 붙은 줄만 사라집니다. 다른 지지줄과 남은 상자 사이의 줄은 유지되며, 지지를 잃은 몸체는 기존 속도·회전을 이어 낙하합니다.

현재 경기의 `CombatTuning`에는 **연결 상자 접촉 안정화**가 기본으로 켜져 있습니다. 작은 상자의 가장자리를 밟을 때 과도하게 회전하며 플레이어에게 피해를 주던 하중 처리를 보완한 설정입니다. 일반 상자·기둥의 기본값은 그대로이며 구 리플레이는 기록 당시 설정을 자동 선택합니다. 접촉·파괴의 검수 순서는 [PLAYTEST 7절](PLAYTEST.md#7-상자-연결망과-독립-연결-상자)을 봅니다.

관통 감속은 연결 상자 Inspector에서 0~100%로 설정합니다. 15%는 속도 85% 유지이고 100%는 그 순간 정지입니다. 차징·던져진 플레이어에 상자 하나당 한 번 적용하며 펀치 사용자를 감속하지 않습니다. 파괴된 연결 상자는 다음 라운드 초기화까지 돌아오지 않습니다.

### 로프 묶음 복제와 기존 맵

상자들을 함께 선택해 **위로 복제 / 좌우 대칭 복사 · 연결 로프 포함**를 사용하면 새 상자 ID로 연결도 복사합니다. 양끝 상자가 모두 선택된 줄과 선택 상자의 고정점 줄이 대상입니다. **선택하지 않은 원본 상자로 이어지는 줄은 복사하지 않습니다.** 로프 Inspector의 함께 복제 버튼은 해당 줄의 양끝 상자를 포함합니다. 한 번 Undo/Redo로 되돌릴 수 있습니다. 미러 복사는 양쪽 로컬 연결점의 X도 반전합니다.

상자 전용 삭제는 그 상자에 들어오거나 나가는 줄을 함께 제거합니다. Hierarchy에서 상자를 직접 삭제해 참조가 끊겼으면 연결 대상을 다시 지정하거나 해당 로프를 삭제합니다. 번호 빈칸은 **도형 순서 정리**로 복구합니다. 현재 상자 한도는 48개, 로프는 96개입니다.

예전 로프는 자동 변환하지 않았습니다. 기존 맵을 열면 이전 규칙이 읽기 전용으로 표시됩니다. 새 제작 UI에서 과거 3종 선택은 제거했습니다. **일반 로프로 전환 · 과거 파단 규칙 제거**를 명시적으로 누르면 그 줄의 과거 파단/표시 규칙을 제거하고 새 일반 줄로 바꿉니다. 별도의 연결 상자는 직접 배치합니다. 변환한 맵의 해시는 달라지므로 과거 리플레이용 원본은 사본으로 보존하세요.

[CP3_Rope_Graph_Trial](../../Assets/_Project/Data/Maps/Validation/CP3_Rope_Graph_Trial.asset)은 왼쪽 연속 매달림, 오른쪽 연결 상자 세 개와 여러 줄로 지지한 발판을 비교합니다. [CP3_Connector_Body_Trial](../../Assets/_Project/Data/Maps/Validation/CP3_Connector_Body_Trial.asset)은 시작 발판 옆에서 세 공격과 감속을 시험합니다. 두 맵은 GameMaps에 등록하지 않았습니다. 자세한 순서는 [검수 7절](PLAYTEST.md#7-상자-연결망과-독립-연결-상자)을 봅니다.

이전 `CP3_Rope_Connector_Trial`, `CP3_Rope_Pull`, `CP3_Rope_Fixed`는 과거 방식의 호환 비교용으로 보존합니다. 새 독립 연결 상자 검수에는 위 두 시험 맵을 사용하세요. 줄 자체의 체력이나 공격 피해 누적은 구현하지 않습니다.

### 고정 지형 두 점 절단

1. Scene에서 일반 고정 지형 하나를 선택하고 Inspector의 **두 점 절단 시작**을 누릅니다. 물리 상자나 통과 발판은 절단 대상이 아닙니다.
2. 경계의 두 점을 클릭합니다. 꼭짓점·변 중간 근처에서는 점이 붙고, 그 외 변 위 위치도 선택할 수 있습니다. 선택 중인 점과 절단선을 미리 표시합니다.
3. **초록 영역은 유지, 빨강 영역은 제거**입니다. **남길 쪽 바꾸기**로 반대편을 선택하고, 취소 또는 Esc로 원래 지형을 유지합니다.
4. **절단 적용** 후 Ctrl+Z 한 번으로 되돌립니다. 다시 적용한 도형도 반복 절단할 수 있습니다. 지형 ID와 판정 순서는 바꾸지 않습니다.
5. **맵 저장 → 맵 불러오기**로 확인한 뒤 미등록 시험을 시작합니다. 이동·크기 변경과 좌우 대칭도 실제 꼭짓점에 반영됩니다. 발 스냅은 몸체가 사선에 걸치지 않는 높이를 사용합니다.

첫 구현은 볼록 지형 3~32개 꼭짓점이며 너무 작거나 일직선인 결과는 거절합니다. 경사 보행은 약 45도까지 지원하고 더 가파른 면에서는 미끄러집니다. 화면·실제 충돌·그림자는 같은 꼭짓점을 사용합니다. 새로운 다각형에서 보류된 무기 기능을 켜는 조합은 지원하지 않습니다.

[CP4_Cut_Rope_Trial](../../Assets/_Project/Data/Maps/Validation/CP4_Cut_Rope_Trial.asset)은 왼쪽 경사, 중앙 절단용 사각형, 오른쪽 적층·통과 기둥·로프를 함께 둔 미등록 시험 맵입니다. 중앙 `Terrain_Box_2`의 윗변 중간 **(0, -2)**와 오른쪽 변 중간 **(2, -4)**를 찍고 우상단을 제거하면 예시 절단을 확인할 수 있습니다. 원본 시험 정의를 남기려면 **현재 배치를 새 사본으로 저장**으로 시작합니다. 사용자의 현재 Brawl_Trial_Test2 편집을 이 시험 맵으로 덮어쓰지 않습니다.

### 미등록 시험과 정식 등록

**정식 경기 목록 · 별도 등록 → 저장한 맵을 GameMaps에 등록**을 눌러 저장한 정의를 등록합니다. 목록은 `Data/Maps/GameMaps.asset`이나 **등록 목록 열기**에서 확인합니다.

- **1개:** 같은 맵을 계속 사용합니다.
- **2~8개:** 직전 라운드와 다른 맵으로 순환합니다. 내부 ID 순서로 목록을 고정한 뒤 경기 시드로 섞어 한 바퀴씩 사용합니다.
- **8개 초과:** 오류로 거절합니다. 일부만 잘라 쓰지 않습니다.

목록 변경은 다음 경기에 적용됩니다. 이름·ID만 다른 같은 지형의 사본도 별도 맵으로 취급하므로, 다음 맵이 화면상 같아 보일 수 있습니다.

`저장한 맵으로 시험`은 **GameMaps에 등록하지 않아도** 선택한 저장 정의 하나와 테마를 실제 Main 실행기로 보냅니다. 로컬 연습이 바로 시작하고 이 시험 경로에서는 등록 목록을 순환하지 않습니다. 방 생성·참가는 시험 중 막습니다. 등록 버튼은 정식 경기 목록에 추가할 때만 따로 누릅니다.

Play를 중지하거나 상단 `Knockbox → 맵 → 시험 종료 및 편집 복귀`를 누르면 편집하던 씬과 이전 시작 씬 설정으로 돌아갑니다. 팀의 Main 에셋에 시험 맵 선택을 저장하지 않습니다. 제작기 기능별 직접 확인은 [플레이 검수](PLAYTEST.md), 현재 데이터·호환 규칙은 [개발 명세](../ai_docs/CURRENT_DEV_SPEC.md#맵-정의와-제작)를 봅니다.

## 보상 맵(카드 선택 장면)

`Data/Maps/CardPick/CardPick_Stage`는 경기 맵이 아닌 보상 맵입니다. 불러오면 바닥(지형) 외에 비석 3개(`Reward_Steles`)와 패자 자리(`Reward_Loser_Stand`)가 나오고, 인스펙터의 "보상 맵 · 카드 선택 장면"에서 광원·원근·점등 시간 같은 장면 값을 고칩니다. 비석은 일반 상자처럼 크기 조절·두점자르기로 만들며, 맵 저장 한 번으로 모두 저장됩니다. 보상 맵은 GameMaps 등록과 "저장한 맵으로 시험"이 막혀 있으니 Main Play에서 세트를 진 뒤 확인합니다. 자세한 규칙은 [기획서](../ai_docs/MONOLITH_CARD_PICK_PLAN.md#보상-맵-편집mapauthoring)를 봅니다.

## 스냅·대칭·테마

### 좌표 정밀도와 스냅

좌표는 기존 `float` 정밀도를 사용합니다. 저장할 때 강제로 반올림하지 않습니다. 바꾸지 않은 상자는 원본 min/max 비트를 보존합니다. 씬을 열거나 저장하는 것만으로 좌표가 바뀌지는 않습니다.

- `격자 맞춤`: 켜면 선택한 지형을 이동하거나 크기를 바꿀 때 지정 간격에 맞춥니다. 기본 간격은 **0.25**입니다. 끄면 자유롭게 배치합니다.
- `캐릭터 발을 지형 윗면에 맞춤`: 시작 마커를 옮길 때 가까운 지형 윗면에 붙입니다. 몸이 다른 지형에 겹치는 후보는 제외합니다. 현재 Brawl의 **0.72 몸 크기** 기준이며 벽 옆면·천장에는 붙지 않습니다.
- 중복되던 수동 스냅 버튼은 숨겼습니다. 위 토글을 켜고 오브젝트를 이동하거나 크기를 바꾸면 적용됩니다.

### 좌우 대칭 복사

지형을 하나 이상 선택한 뒤 **선택 지형 좌우 대칭 복사**를 누릅니다. 맵 중앙 `x=0` 반대편에 사본을 만듭니다.

원본·높이·크기·종류는 유지하고, 사본에는 새 ID와 순서 번호를 부여합니다. 위치와 종류가 정확히 같은 지형은 중복 생성하지 않습니다. 복사한 묶음은 한 번의 Undo로 되돌릴 수 있습니다.

시작 위치는 자동 복사하지 않습니다. 복사는 씬 배치만 바꾸므로 **맵 저장**으로 정의에 반영하세요.

### 색상과 배경 그라데이션

제작기 하단 **맵 테마**에서 설정합니다.

- `기존 테마`: 이전 색상을 유지합니다.
- `프리셋`: 깊은 청록·보랏빛 밤·은은한 노을·고요한 숲 중에서 고릅니다.
- `직접 설정`: 배경 위/아래색, 그라데이션 곡선, 땅·구조물·강조색을 조정합니다.
- `이 색상으로 직접 편집`: 프리셋을 출발점으로 삼아 직접 조정합니다.

테마도 `맵 저장` 후 시험합니다. 지형 색은 씬에서, 그라데이션은 Inspector 색상 띠와 실제 경기에서 확인합니다.

색상은 연출 전용이라 맵 판정 체크섬을 바꾸지 않습니다. 플레이어·HUD 식별색은 유지합니다.


## CP5 통합 검수

[CP5_Integrated_Trial](../../Assets/_Project/Data/Maps/Validation/CP5_Integrated_Trial.asset)은 별도 미등록 정의입니다. 기존 Brawl·GameMaps·사용자 편집 맵은 변경하지 않았습니다.

1. 현재 맵을 저장한 뒤 이 정의를 불러오고 **현재 배치를 새 사본으로 저장**합니다.
2. 중앙 `Terrain_Box_2`를 선택해 윗변 중간 `(0, -2)`과 오른쪽 변 중간 `(2, -4)`을 찍습니다. 우상단이 빨강이면 **절단 적용**합니다. 필요하면 남길 쪽을 바꾸거나 Undo합니다.

5. **저장한 맵으로 시험**합니다. 왼쪽 경사와 절단 면의 충돌, 적층의 정지·약한 밀기·강한 차징, 기둥 통과를 봅니다. 오른쪽 발판으로 점프한 뒤 연결 상자에 서기/점프와 공격 파괴를 구분합니다. 아래 상자로 이어지는 줄은 연결 상자를 부숴도 남아야 합니다.

2026-11-11 사용자가 제작기 Unity 검수 완료를 승인했습니다. 위 순서는 이후 회귀 확인에 사용합니다. 현재 빌드·자동 검사·사용자 멀티플레이 확인은 [PROGRESS](../ai_docs/progress/PROGRESS.md)에 구분해 기록합니다.
